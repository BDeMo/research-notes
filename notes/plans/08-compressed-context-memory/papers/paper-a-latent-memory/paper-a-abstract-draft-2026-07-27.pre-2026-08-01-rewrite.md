# Paper A Abstract Draft

## Current refined draft

Large language model agents are becoming capable enough to revolutionize how people work. A coding agent can navigate codebases that are impractical for one person to inspect in full, analyze execution traces, and resume unfinished tasks. A research agent can synthesize evidence across large document collections. Long context serves as the working memory for these agents. However, the memory budget is finite. As tasks become more complex, their histories grow and must be selected or compressed. This creates a fundamental reliability problem. Evidence required by the current query may be distant or distributed across the history, and compression may remove it. Even without compression, a model may fail to use relevant evidence that is present in a long input. Long-context agents therefore require memory that preserves query-relevant evidence and reports when that evidence may have been lost. To meet this requirement, we introduce Gated Context Memory (GCM), a query-aware and self-assessing memory compressor. GCM addresses the limited memory budget by consolidating long histories into compact soft memory. It addresses silent evidence loss by producing a confidence signal that estimates whether the evidence required by the query survived compression. GCM therefore learns both what to remember and when its memory may be unreliable. A lightweight interface provides these two capabilities over a frozen backbone, without training a separate verifier. Across models and long-context settings, GCM outperforms recent compression methods and strong budget-matched baselines in key settings. Its compact state preserves useful information across backbones. Confidence-guided routing further improves decisions when compression alone is insufficient. The results show a task-dependent boundary: compact memory helps when bounded raw input loses distributed evidence, while confidence indicates when the system should use another memory path. These findings support a broader principle for long-context agents: memory compression should be paired with an explicit estimate of compression quality.

## Iteration process

1. **Start from importance, not implementation.** The abstract moved from a technical summary of recurrent compression and fallback to the broader problem: long context is the working memory of capable agents, but the memory budget is finite.
2. **Make the consequence concrete.** Coding and research agents were added as examples. The abstract now explains that one missing requirement, test result, function, or piece of evidence can change the next decision.
3. **Explain why compression is difficult.** Relevant evidence is query-dependent and may be distant or distributed. Compression can silently remove it, while even uncompressed long context can fail to use it.
4. **Turn the method into a punchline.** GCM is presented as self-assessing compression. It learns not only what to remember, but also when not to trust its own memory.
5. **Clarify the role of confidence.** The score is not presented as generic answer confidence. It measures whether the compressed evidence supports the current query and gives the surrounding agent system an actionable robustness signal.
6. **Keep the abstract advertisement-focused.** Detailed benchmark names, task inventories, negative findings, and formal certification details were removed. The abstract keeps only the strongest validated gains.
7. **Keep the strongest practical advantages.** GCM uses a frozen backbone, needs no separate verifier, and combines compact memory with measurable robustness.

## Previous version: concise advertisement draft

This was the version approved before adding the self-assessing-compression punchline.

LLM-based agents now support reasoning, tool use, and knowledge work. Long context is a key part of this progress. It lets an agent use complete documents, codebases, tool traces, and interaction histories. However, an agent's memory budget is limited, and no system can keep every token forever. As the context grows, the system must decide what to keep, compress, or discard. This choice is difficult because relevance depends on future queries that may not be known when the memory is formed. Important evidence may also be distant or distributed across the history. A coding agent may need an early user requirement, a recent test failure, and a function from another file. A research agent may need evidence spread across many documents. One missing detail can change the next decision. Once discarded, that detail cannot be recovered from the compressed state. Current compression methods shorten the context, but they can silently remove exactly such evidence. Long-context agents need more than larger context windows. They need memory that knows what to preserve and can tell the system when that memory should be trusted. We introduce Gated Context Memory (GCM), a query-aware memory compressor built for robust long-context use. GCM not only turns growing histories into fixed-length soft memory, but also provides a confidence score for each memory-based decision. The score measures whether the compressed evidence meets the needs of the current query. It makes compression quality visible to the agent system and gives the system an actionable signal when information may be missing. GCM therefore provides compact memory and measurable robustness in one interface. Across diverse models and long-context settings, GCM's compressed memory improves over recent compression methods. Its confidence signal further improves final accuracy by up to 22.0 percentage points. Together, they increase the advantage over recent compression methods to as much as 24.6 points. The complete system also gains up to 32.8 points over strong budget-matched baselines. Its confidence score identifies compression failures with an AUROC of up to 84.1. These results show that GCM provides both strong compression and measurable robustness.

## Previous version: robustness-centered technical draft

This version followed the introduction closely, but read more like a technical summary than an advertisement.

Reliable memory is a basic requirement for language-model agents to move from short interactions to sustained work. As an agent accumulates user requirements, observations, tool results, and intermediate decisions, its history grows without bound. Discarding that history makes the agent repeat work, violate earlier constraints, and lose progress; repeatedly reading it makes every later step more expensive. Compression appears to remove this limit, but creates a more dangerous failure: a compact memory can silently omit the evidence needed for the next action while the model remains confident. Scalable agent memory therefore requires more than compression—it requires deciding when compressed memory can be trusted. We formulate this as a paired reliability problem: use a compact state when it preserves the required evidence, and return to raw context when it does not. We introduce Gated Context Memory (GCM), which combines recurrent soft consolidation, a small read adapter, held-out failure detection, and bounded raw fallback within one shared frozen language model. Across document reading, tool use, and multi-hop question answering, GCM consistently improves over simple latent pooling and often over a matched raw window; the same recipe also transfers across seven base models. Retrieval and text compression remain stronger on some tasks, confirming that no single memory representation is reliable everywhere. Empirical routing recovers accuracy by switching representations, while stricter finite-sample analysis exposes the gap between useful routing and certified safety. Together, these results turn context compression from a fixed preprocessing step into an adaptive memory interface, opening a path toward agents that can work for longer without forgetting what their decisions depend on.

## Alternative draft from the other agent

This version introduced the stronger opening example and emphasized the shared-backbone design, but included more implementation and operating-boundary detail.

Large language model agents are becoming capable enough to revolutionize how people work and build software: a coding agent navigates a large codebase, reads execution traces, and resumes an unfinished task, while a research agent synthesizes evidence spread across many documents. In these settings long context is the working memory of the system: it holds documents, code, tool descriptions, conversation history, observations, and the unfinished work of an agent. But as task complexity grows, context length explodes and creates a critical bottleneck: the input may exceed the available budget, so long context must be compressed, and compression does not guarantee that the fact or relation needed for the next decision survives. Existing work further shows that even an input that fits may not be used reliably, so needed evidence can be missed without any compression at all.

We introduce Gated Context Memory (GCM), a recurrent soft-memory interface with a shared-backbone raw fallback. A recurrent compressor consolidates long context into a short soft memory that retains the information needed for the next decision. The reader answers from that memory, estimates confidence in whether the memory is lossy, and returns to bounded raw evidence when the memory is judged insufficient, preserving the needed information. To save development and maintenance effort, GCM introduces no separate memory model: the agent's own frozen language model plays every role, building the memory, reading it through a small adapter, estimating confidence, and providing the raw fallback. The backbone is never fine-tuned, and no second language model or external verifier is required.

GCM improves over simple latent mean pooling on all three main tasks and over a matched raw window on tool use and multi-hop question answering. Retrieval and text compression can be stronger on individual tasks, which motivates detecting when compressed memory is insufficient. Through extensive experiments, the same recipe gives consistent tool-use performance across seven base models, showing that the approach generalizes across backbones. This operating boundary is task-structured: in zero-shot long-context transfer, compact memory helps most on multi-hop targets, where bounded raw input truncates away distributed evidence, whereas on single-document and extractive targets that favor raw context, the empirical routing falls back to it without giving up the raw evidence those targets rely on.

Taken together, this paper takes a robustness-centered view and presents a low-loss soft-memory method for agents, one that focuses not only on how much it compresses, but on whether the information needed for the next decision can always be recovered by the agent.
